# Homie

A modern, elegant property rental platform for finding your ideal home or listing your property for rent. Built with Next.js, Tailwind CSS, and Framer Motion.

![Next.js](https://img.shields.io/badge/Next.js-16-black)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-38bdf8)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-12-purple)

## Features

- **Animated Hero Section** with scroll-triggered animations
- **Property Stats** with real-time counters
- **Services Showcase** with interactive cards
- **Feature Comparison** grid
- **Pricing Plans** with toggle options
- **Testimonials** carousel
- **FAQ Accordion** with smooth transitions
- **Responsive Design** for all devices
- **Dark/Light Theme** support

## Tech Stack

- **Framework:** Next.js 16
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **UI Components:** Radix UI
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
